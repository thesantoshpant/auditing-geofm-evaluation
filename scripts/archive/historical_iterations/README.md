# Historical Analysis Snapshots

These files preserve analysis and launch logic from superseded pilot and
revision iterations. They are non-executable snapshots: their paths, tags, and
filenames describe the earlier release layouts and are intentionally not
maintained as current commands.

Use the scripts directly under `scripts/` to reproduce the camera-ready paper.
In particular, `scripts/reproduce_all.sh` regenerates the released aggregates
and verifies the canonical checksum manifest.
